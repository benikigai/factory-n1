      The stack, measured

      What each sponsor uniquely made possible.

      Crusoe Managed Inference

      One OpenAI-compatible endpoint serving Nemotron 3.5 Super VL the day after launch, with MemoryAlloy prefix caching.

      Our shared Playbook is rendered byte-stable, so it doubles as a cacheable prompt prefix: cached prompt tokens grew as memory grew.

      NVIDIA Nemotron 3.5

      Super VL designs and reflects through typed tool calls; Lightning runs research and isolated test interventions cheaply.

      Strong at structured proposals under a tool contract, and it over-claims. So predictions are graded and causes come from receipts.

      You.com Search

      boost_domains, token-budgeted highlights and search receipts, with every citation checked against the exact returned URLs.

      Web ideas enter memory as hypotheses and earn trust only through an isolated simulator test. In our runs none did, and we say so.
