The problem

A factory floor gets drawn once. Demand keeps changing.

Redesigns are slow and risky. AI agents can propose them, but they grade their own work. One of ours reported a simulator run that never happened.

So the agents draw, and code decides.

Version N+1

Every change is a revision.

Nemotron agents propose a floor and predict its score. A frozen simulator runs 100 packages through it. It ships only if it beats the current floor by at least 1% on 9 validation days and no goal check gets worse.

Revision history

Each card is one version of the floor. A change ships only if it beats the last one on 9 held-out days. Score is seconds to clear the floor plus penalties. Lower is better.

What's next

Today the nodes are stations. Receive, sort, pack, ship.

Next they are humanoid robots, vision models and world models. Each one drops in as a node the simulator can score. The agents design around it. The gate stays the same.

The loop works for anything a simulator can measure. A fulfillment floor is the first one.

The floor is never finished. It ships its next revision.
